# Input files

Extract `train.csv` (and optionally `test.csv`) from the supplied
`teta-ml-1-2025.zip` into this directory. Keep their basenames unchanged.
`sample_submition.csv` is a prediction template and is not ingested.

The repository includes `demo.csv`, a 20-row synthetic example for repeatable
smoke tests. Raw Kaggle files remain outside Git; the exact source hashes and
row counts are recorded in `../results/dataset_summary.json`.
